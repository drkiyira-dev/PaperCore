## 它是什么

PaperCore 是一套**本地优先**的论文核心内容提取与结构化阅读系统，面向需要快速读懂论文的在校学生与研究生。它把 PDF / DOCX / TXT / Markdown 论文在本机自动解析，以结构化卡片呈现一篇论文「做了什么、怎么做的、结果如何」。

处理分五层，**前四层完全在本机运行**，第五层云端 AI 增强为可选项。即使不联网、不填任何 API Key，系统也能完成基础的结构化分析——这正是它**「并非简单 AI 套壳」**的根基：大模型只是一个可替换的零件，而不是系统的地基。

---

## 给谁用，解决什么痛点

| 目标用户 | 痛点 | PaperCore 怎么解 |
|---|---|---|
| **学生 / 考研党** | 论文读得慢，抓不住一篇到底「做了什么、怎么做、结果如何」 | 30 秒速读，直接给出核心三要素 + 答辩大纲 |
| **科研人员 / 研究生** | 海量论文里快速筛选定位，公式和实验数据不能读错 | 公式/变量保护 + 实验数据提取，六维结构化解析 |
| **隐私敏感场景**（未发表稿、涉密课题） | 不敢把原文丢进云端大模型 | 本地模式**完全离线**运行，文件与正文不出本机 |

---

## 为什么不是「直接用大模型就行了」

答辩最常被问的问题。核心回答：**PaperCore 是系统，大模型是它内部一个可替换的零件。**

| 维度 | 直接调用云端大模型 | PaperCore |
|---|---|---|
| 部署 | 云端，数据出境 | 本地优先，隐私安全 |
| 输入 | 纯文本 | PDF / DOCX / TXT / MD 多格式，含扫描件本地 OCR |
| 抽取结构 | 靠 prompt 临时拼 | 固化规则引擎 + 可定制领域先验 |
| 打分依据 | 无 | 显著度 salience，挂 TF-IDF / RAKE / YAKE 文献锚点 |
| AI 依赖 | 必须联网 | 不填 Key 即走本地规则，可完全离线 |
| 模型可换 | 锁死单一模型 | 纯规则 / 本地小模型 / 本地大模型 / 云端 API 自由切换 |

## 实测效果（小样本量化评测）

为回答「本地规则到底能达到什么效果」，在 **10 篇真实工科论文**（中英混合，跨脑电、心电、遥感、医疗、系统、通信等方向）上做了**人工标注金标准**的小样本评测：

| 评测维度 | 结果（n=10） |
|---|---|
| 本地规则 · 标准章节识别 | 微平均 **P 0.98 / R 0.78 / F1 0.87** |
| 核心方法句提取 | **Recall@10 0.74** |
| AI 增强 · 信息完整度提升 | 平均 **+69%** |

其中章节识别与核心句召回**完全基于本地规则与显著度排序、断网条件下可复现**。

> **诚实边界**：这是 10 篇的小样本初步评测，不夸大为大规模泛化结论；当前显著度为启发式评分，概率校准列为未来工作。

## 核心能力

- **🔍 智能章节识别** —— 自动识别摘要、引言、方法、实验、结论等标准章节。
- **∑ 公式与变量保护** —— 精确提取数学公式与变量定义，保持符号系统完整。
- **📊 实验数据提取** —— 识别表格、图表数据与关键实验结论。
- **🎯 显著度打分（salience）** —— 给每个抽取片段一个有文献依据、可追溯的重要性分数。
- **🖨 扫描件 OCR** —— 无文字层的扫描 / 拍照论文，自动用本地 OCR 兜底识别。
- **📑 结构化报告** —— 生成结构化报告，支持 TXT / Markdown 导出。
- **🗂 分析历史 / 我的文档 / 报告中心** —— 本地保存与回看分析记录、文件库与批量导出。
- **🌐 中英双语界面** —— 界面支持中 / 英文切换。

### 四种分析模式

| 模式 | 用途 |
|---|---|
| ⚡ 30 秒速读 | 提取核心三要素，快速判断要不要细读 |
| 🔬 结构化理解 | 六维深度解析，完整结构化报告 |
| ∑ 公式/实验保护 | 精确保留技术数据与符号 |
| 🎓 答辩汇报 | 直接生成答辩大纲 |

## 显著度（salience）：打分有据可依

老式做法用一条拍脑袋的公式 `conf = min(0.95, 0.4 + len/50)`——长度越长分越高，无任何理论依据。PaperCore 把它重构为**显著度 salience**，挂三个公认的关键词/重要性度量作为文献锚点：

- **TF-IDF** —— Spärck Jones, 1972
- **RAKE** —— Rose et al., 2010
- **YAKE!** —— Campos et al., 2020

打分逻辑独立成 [`salience.py`](salience.py)，并提供可复现自检脚本 [`salience_selfcheck.py`](salience_selfcheck.py)。

---

## AI 引擎是可插拔的

[`ai_engines.py`](ai_engines.py) 通过统一的 `AIEngine` 接口，提供由轻到重的多档引擎，体现「AI 是可替换组件」：

1. **SimpleAI** —— 纯本地，jieba 规则替换 + 词频摘要 + 关键词抽取，零联网。
2. **LocalModelAI** —— 本地开源小模型（中文 T5），离线润色/摘要。
3. **OllamaAPI** —— 本地大模型，通过 [Ollama](https://ollama.com)（默认 `deepseek-r1:7b`）在本机运行，不出网做深度分析。
4. **CloudAPI** —— 云端可切换：DeepSeek / 豆包 / 通义。
5. **V4ProAPI** —— 高级分析模式，更深的结构化评审，带 5 小时滚动配额（freemium 形态）。

不配置任何 Key 时默认走本地路径；装了 Ollama 后即可让本地大模型完成深度分析，**全程不出本机**。

## 技术栈

| 层 | 用到的东西 |
|---|---|
| Web | Flask（本机 127.0.0.1:5003） |
| 文档解析 | docling → pdfplumber → PyPDF2 → RapidOCR 四级降级 |
| 扫描件 OCR | RapidOCR（本地 ONNX，自带中英文模型）+ PyMuPDF 渲染 |
| 规则引擎 | [`rules.py`](rules.py)（含领域先验） |
| 显著度打分 | [`salience.py`](salience.py) |
| 中文处理 | jieba / jieba.analyse |
| AI 引擎 | [`ai_engines.py`](ai_engines.py)（规则 / 本地 T5 / Ollama / 云端 API） |
| 稳健解析 | json_repair（修复本地大模型残缺 JSON 输出） |
| 前端 | 原生 HTML/CSS/JS，自托管字体 |

## 快速开始

```bash
# 1. 安装依赖
pip install flask python-dotenv docling pdfplumber PyPDF2 jieba requests json_repair
#   扫描件 OCR（本地）：pip install rapidocr_onnxruntime pymupdf
#   本地大模型（可选）：安装 Ollama 并 `ollama pull deepseek-r1:7b`

# 2. 启动
python app.py

# 3. 浏览器访问
#    http://127.0.0.1:5003
```

- **离线使用**：不填 API Key，直接上传论文，全程走本地规则与本地模型，数据不出本机。
- **联网增强（可选）**：在首页填入 DeepSeek API Key（或在 `.env` 配置），即可调用云端模型做深度分析。

## 设计原则

1. **本地优先（local-first）** —— 隐私是默认值，不是开关。
2. **可解释优先** —— 每个分数都能说清依据、挂上文献。
3. **AI 可替换** —— 大模型是零件不是地基，换模型不动主流程。
4. **诚实边界** —— 是启发式就说是启发式，未做的明确标注为未来工作。
