よくある質問

良い質問に、まっすぐな答えを。

これは ChatGPT のラッパーですか？

いいえ。顕著度ランクづけとルールエンジンがローカルで動き、中心的な処理を担います。大規模言語モデルはオプションで、初期状態はオフ——Paper Core はオフのままでも完全に機能します。

プライバシーはどう守られますか？

すべてがあなたの端末で動作します。何もアップロードされず、アカウントも不要、完全にオフラインで動きます。ソースコードでご確認いただけます。

どんな論文を読めますか？

ネイティブおよびスキャン PDF（オンデバイス OCR）、日本語・英語の文書、長い論文、数式・表・図を含む内容に対応します。

無料でオープンソースですか？

はい。Paper Core は MIT ライセンスで、パイプライン全体が GitHub にあります——サービスの裏に隠れたものはありません。

論文を読む代わりになりますか？

いいえ——コアを浮かび上がらせ、すべての行を原文の該当箇所に紐づけます。だから、本当に大切なところに読む時間を使えます。
